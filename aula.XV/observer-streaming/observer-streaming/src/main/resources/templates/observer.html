Streaming Observer 📖 Padrão Observer

O padrão Observer é um padrão comportamental que estabelece uma dependência um-para-muitos entre objetos: quando o subject muda de estado, todos os observers registrados são notificados automaticamente.

Papéis principais:

  • Subject: mantém uma lista de observers e fornece métodos para registro/remover e para notificar mudanças.
  • Observer: interface que define o método `update()`; implementações reagem às notificações.
  • ConcreteSubject / ConcreteObserver: implementações concretas que carregam dados e comportamento específicos.
