Streaming Observer ℹ️ Sobre o Projeto
Contexto do trabalho

Sobre a solução

Uma apresentação simples e funcional para demonstrar o padrão Observer em uma plataforma de streaming.

Descrição

Projeto desenvolvido para a disciplina de Padrões de Projeto. O objetivo é implementar o padrão Observer em uma plataforma de streaming semelhante à Netflix, permitindo que os usuários escolham gêneros e recebam notificações automáticas quando novos conteúdos forem adicionados.

Tecnologias
Java 17 Spring Boot HTML CSS JavaScript Bootstrap
