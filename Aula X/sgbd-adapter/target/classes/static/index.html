SGBD Adapter

Selecione um perfil de usuário e simule operações CRUD no banco de dados correspondence.

👋 Olá, Professor Fernando! Como usar esta aplicação:
  1. Selecione um Perfil (Etapa 1): Cada perfil está amarrado a um SGBD diferente com capacidades distintas.
  2. Faça Operações (Etapa 2): Clique nos botões para executar métodos genéricos (ex: inserir(), conectar()).
  3. Observe o Terminal: O código Client em Java não sabe qual SGBD está usando. Quem traduz o commando para as strings e peculiaridades do Paradox, Firebird ou MySQL é o nosso Adapter!
  4. Dica: Clique em ▶ Demo Completo para visualizar todo o ciclo CRUD em lote.
  5. Diagrama UML: Role a página até o final para visualizar o Diagrama de Classes completo modelado dinamicamente!

① Selecione o perfil do usuário

② Execute operações no banco de dados

④ Diagrama de Classes UML Completo

classDiagram
    %% ── Cliente e Fabrica ──
    class SGBDService {
        <<Client>>
        +executarOperacao(req: OperacaoRequest) OperacaoResponse
        +executarDemo(perfil: String) DemoResponse
    }

    class SGBDAdapterFactory {
        <<Factory>>
        +criarAdapter(perfil: PerfilUsuario) SGBDAdapter
    }

    class PerfilUsuario {
        <<enumeration>>
        GRATUITO
        BASICO
        ULTIMATE
    }

    %% ── Interface Alvo ──
    class SGBDAdapter {
        <<Target Interface>>
        +conectar() String
        +inserir(dado: String) String
        +consultar(query: String) String
        +atualizar(dado: String) String
        +deletar(dado: String) String
        +desconectar() String
        +getNomeSGBD() String
        +getCapacidades() String
    }

    %% ── Adapters Concretos ──
    class ParadoxAdapter {
        <<Adapter>>
        -paradox: Paradox
        +conectar() String
    }

    class FirebirdAdapter {
        <<Adapter>>
        -firebird: Firebird
        +conectar() String
    }

    class MySQLAdapter {
        <<Adapter>>
        -mysql: MySQL
        +conectar() String
    }

    %% ── Adaptees ──
    class Paradox {
        <<Adaptee>>
        +abrirArquivoDb(caminho: String) String
        +gravarRegistro(registro: String) String
    }

    class Firebird {
        <<Adaptee>>
        +conectarServidor(host: String, porta: int, banco: String) String
        +inserirRegistro(tabela: String, dados: String) String
    }

    class MySQL {
        <<Adaptee>>
        +abrirConexao(url: String, usuario: String) String
        +executarInsert(sql: String) String
    }
